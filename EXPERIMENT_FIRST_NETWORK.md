# First Heston SuperEncoder experiment

The new code lives in the repository root: `synthetic_states.py`, `training_workflow.py`, and `main.py`. It reuses the repository's existing `mlp.py`, `loss.py`, `circuits/`, and `heston/distributions.py`.

Dependencies: NumPy and PyTorch.

## Run the full chronological experiment

```bash
python main.py
```

The defaults are:
- First **150** dated calibrations (2013-01-02 through **2013-08-08**) converted to eight-qubit, real nonnegative amplitude-encoded quantum states. These are anchors, not teacher circuit angle labels.
- **850** further quantum states, generated by perturbing the **amplitudes directly**, without perturbing any Heston parameters.
- Radius: the 75th percentile of consecutive Fubini–Study distances within those 150 anchors. For each new sample, choose an anchor in balanced fashion, generate a smooth nonnegative amplitude-space reference, and spherical-interpolate a distance uniformly between 10% and 100% of that radius.
- Train the eight-qubit **18-layer brickwork** SuperEncoder for 10 epochs on 1,000 states; Adam learning rate 0.003, batch size 64, weight decay 1e-5; use the original `Tanh`-bounded MLP angle head.
- Freeze the MLP and evaluate the subsequent **100** dated Heston states (2013-08-09 through 2013-12-31).

Outputs under `results/first_heston_network/`:
- `model.pt`: trained model with architecture metadata
- `training_progress.pt`: after-each-epoch checkpoint, including optimiser and loader state
- `training_states.npz`: original anchors, synthetic states, parents and geometric distances
- `train_history.csv`: loss and fidelity across training
- `future_test_results.csv`: dates, preparation fidelities and distances from historical anchors
- `summary.json`: experiment settings and aggregate results

To resume a run interrupted after an epoch:

```bash
python main.py --epochs 10 --resume
```

For *newly calibrated future dates*, load the already-trained model **without retraining**:

```python
from training_workflow import read_heston_states, load_checkpoint, evaluate_network

dates, target_states = read_heston_states("my_later_calibrations.csv")
model = load_checkpoint("results/first_heston_network/model.pt")
fidelities = evaluate_network(model, target_states)
for day, fidelity in zip(dates, fidelities):
    print(day, fidelity)
```

The CSV columns must be `date,theta,kappa,sigma,rho,v0`, and its dates must be strictly increasing. Numerical settings match `heston/distributions.py` (`n_fft=16384`, `halfwidth=3.5`, `cutoff=2.5`, one-year maturity, 0.05 drift).

**Caveats:** Augmented real nonnegative quantum states are valid amplitude encodings but need not correspond exactly to Heston-parameterised distributions; they are *not* 850 independent real market observations. This is one-seed baseline training and no independent validation-period-based hyperparameter selection. Do not select parameters based on the held-out test results when making confirmatory claims.
